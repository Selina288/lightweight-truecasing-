# 等量训练数据的跨 genre 实验

已完成 **50 次新的 C 模型训练**：5 个目标 genre × 2 种训练来源 × 5 次随机抽样。每次都用 **20,000 个有大小写标签的训练词**，在相同的目标 genre dev 集上评估。使用原 C 的特征与参数；仅改变抽到的训练词，模型求解器种子始终为 42。

“同 genre”指目标 genre 的训练数据；“其他 genre”指其余四个 genre 的训练数据混合。抽样不放回，不按标签挑数据。上下文保留原句相邻词的小写形式，不将抽样后的词重新拼成句子。词形标签和 mixed-case 词典只来自抽中的词。

## 结果：主要指标 macro-F1

| 目标 genre | 同 genre：均值 ± 标准差 | 其他 genre：均值 ± 标准差 | 同 − 其他 | 同 genre 分数较高次数 |
| --- | ---: | ---: | ---: | ---: |
| answers | 0.4359 ± 0.0126 | 0.4591 ± 0.0272 | -0.0231 | 0/5 |
| email | 0.5820 ± 0.0177 | 0.4464 ± 0.0282 | +0.1356 | 5/5 |
| newsgroup | 0.5237 ± 0.0075 | 0.4652 ± 0.0075 | +0.0585 | 5/5 |
| reviews | 0.4380 ± 0.0063 | 0.4362 ± 0.0044 | +0.0018 | 4/5 |
| weblog | 0.6032 ± 0.0041 | 0.5302 ± 0.0370 | +0.0730 | 5/5 |

例如 email：同 genre 的平均分是 0.5820，其他 genre 是 0.4464，五次抽样中同 genre 都较高。reviews 的均值只差 0.0018，其中一次方向相反，不能据此断言谁稳定更好或两者等效。

## 可以写进论文的结论

**控制监督训练词数后，训练数据来源仍影响结果，但同 genre 训练的优势取决于目标 genre。** email、newsgroup、weblog 的同 genre macro-F1 在五次抽样中均较高；answers 则五次都是其他 genre 较高；reviews 的差距很小。

因此，不能写成“跨 genre 一定下降”或“同 genre 一定更好”。也不能写“已经证明 genre 是唯一原因”：虽然监督词数相同，词汇、标签比例、文档数、上下文词暴露量、四种来源混合的多样性仍不同。

## 怎么理解波动

“±”是五次抽样分数的样本标准差，描述换一批训练词后分数有多少变化。它不是置信区间，也没有做显著性检验；五批训练样本可能重叠。该结果只对应当前 20,000 词预算和固定 dev 集。

这是看过原 test 结果后的探索性 dev 补充实验。本次没有读取新的 test 词、没有更换原 C 模型或覆盖原 test 结果。它补上了原先“训练数据量不一致”的一个证据缺口，不是一次新的最终 test。

## 文件

- `dev_summary.tsv`：每个 genre、条件的五次平均分和标准差。
- `dev_runs.tsv`：50 次运行的完整分数。
- `dev_paired_gaps.tsv`：同 genre 减其他 genre 的差值、波动及胜出次数。
- `dev_per_class.tsv`：每次运行的四类分数。
- `run_metadata.json`、`verification.json`：训练记录与复核结果。
- `REPORT.md`：可供队友阅读的英文说明。

原模型和原结果保持不变。源代码为 `src/size_matched_genre.py`，独立复核为 `src/verify_size_matched_genre.py`；模型与逐词预测只保存在本地忽略目录中。实验前 37 项测试通过。
