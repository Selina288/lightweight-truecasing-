# Lightweight Truecasing for Informal English

A cross-genre study of restoring observed capitalization from lowercased UD English EWT tokens. We compare lexical memorization, local context and character features across five web genres.

**Team:** Selina Yao, Jessie Zhang and Adrian Berkmans.

## Current status

Preprocessing, three baselines, three Logistic Regression variants, development feature comparisons, all-genre/in-genre-only/held-out-genre experiments, development error analysis, final frozen test evaluation and a local web demo are complete. The team has confirmed eight selected development examples; the other eleven retained examples remain unconfirmed. Confirmation is user-reported, not an inter-annotator agreement study.

The original proposal and progress notes are retained in [the historical archive](docs/PROPOSAL_AND_PROGRESS_ARCHIVE.md). CRF and pretrained comparisons were proposed but were not implemented. Proposed responsibilities do not establish actual contributions.

## Final official test results

Scores exclude tokens without cased letters. The primary metric is macro-F1 over four fixed casing classes, derived from reconstructed output forms; exact-form accuracy breaks exact ties. Gold is observed corpus spelling, not corrected edited-English casing.

| System | Exact-form accuracy | Four-class macro-F1 | Capitalization-required accuracy |
| --- | ---: | ---: | ---: |
| All lowercase | 80.25% | 0.2226 | 0.00% |
| Sentence initial | 86.26% | 0.3695 | 37.33% |
| Most frequent training form | 85.73% | 0.4905 | 38.46% |
| A Lexical and position | 89.72% | 0.4990 | 59.15% |
| B Context | 90.27% | 0.5175 | 63.29% |
| C Context and characters | 91.50% | 0.5823 | 71.65% |

C was selected using development results before final testing. On the same 1,652 test tokens unseen in full training, C reaches 68.16% exact accuracy versus 59.38% for B. Differences are descriptive; no significance tests or confidence intervals were performed. See [the final report](results/final_test/REPORT.md), [all-system scores](results/final_test/all_systems_summary.tsv) and [genre conditions](results/final_test/genre_overview.tsv).

## Models and evaluation

- A uses the current lowercase word, sentence-initial position and scaled length.
- B adds the previous and next lowercase tokens within supplied sentence boundaries.
- C adds prefixes/suffixes of lengths 1–4 and normalized binary character 2–4 grams.
- All use Logistic Regression with SAGA, C=1, max_iter=500, tolerance=0.001 and seed=42. Feature mappings and mixed-case reconstruction dictionaries use training data only. No gold POS or pretrained embeddings are inputs.
- B/C are evaluated under all-genre, target-genre-only and other-four-genre training. Training sizes differ; transfer gaps do not isolate a causal genre effect. Degradation is not universal.

Labels are lowercase, initial_uppercase, all_uppercase and mixed_case; a single-letter capital such as I is initial_uppercase. Unseen mixed-case spelling cannot be generated by the lexical fallback. Official scoring uses corpus tokenization and sentence boundaries; the demo has a simpler tokenizer.

## Install and run

The recorded environment uses Python 3.14.0 and [pinned requirements](requirements.txt). Other Python/platform combinations were not freshly validated by this cleanup. Run commands from the repository root.

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python src/verify_team_review.py
```

The recorded research run passed 27 tests. After this cleanup, all 31 tests pass (the original 27 plus four repository-record checks). The review command checks the current 8/11 split using tracked files only. See [the cleanup verification](docs/REPOSITORY_CLEANUP_CHECK.json).

### Data and real-model demo

Data and model weights are intentionally excluded from Git. Follow [the reproducibility guide](docs/REPRODUCIBILITY.md) to obtain and check the corpus. The saved source README identifies v2.18; the exact file hashes identify the experiment inputs, rather than upstream's moving master branch.

After placing the three matching files under `data/raw/UD_English-EWT/`, run the following in a separate fresh checkout. Training creates local demo models; do not train over the original frozen model directory.

```bash
python src/check_data.py
python src/preprocess.py
python src/check_data.py --processed
python src/ablation.py --output-dir results/reproduced/ablation
python src/demo_server.py
```

Open http://127.0.0.1:8765 and keep the terminal running; stop with Ctrl+C. Without data/models, the server still provides the two data-free baselines and disables unavailable choices. See [the Chinese demo guide](DEMO_GUIDE_zh.md).

## Limitations and attribution

Character features improve overall and unseen-word scores, but some predictions and metrics regress. Rare uppercase and mixed-case forms remain difficult. Informal gold may be inconsistent or expressive. Selected examples are illustrative, not a random sample. Development informed feature design; no test-driven retuning, downstream benefit, state-of-the-art result, sequence model or pretrained comparison is claimed.

The demo runs locally, preserves punctuation/spacing and highlights case changes. Its displayed metrics are saved **dev** results, not accuracy on a typed sentence. It is not a public deployment.

Data originate from [Universal Dependencies English EWT](https://github.com/UniversalDependencies/UD_English-EWT). Corpus-derived excerpts retain CC BY-SA 4.0 terms; see [the retained data license](results/error_analysis/DATA_LICENSE.txt). Contexts are shortened with target brackets added. Prior-work references remain in the historical archive.
